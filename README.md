# MAX Bridge

Плагин для DeepSeek Harness (Cordis): чат-бот в мессенджере MAX как пульт управления агентом.

Сообщение из MAX мгновенно попадает в сессию как пользовательское, ответ уходит обратно в чат, а пока агент работает — в MAX горит «печатает».

## Как работает

```
MAX  ──long-poll──>  плагин  ──sessionController.prompt()──>  сессия DeepSeek
                      │
                      └── POST /chats/{id}/actions {"action":"typing_on"}  ──> «печатает»
```

## Установка

1. Создайте бота в MAX и получите токен.
2. Положите токен и `chat_id` в `~/.dsh/max-bot.json`:

```json
{ "token": "<токен бота>", "chat_id": 123456789 }
```

3. Установите плагин в профиль Harness:

```js
plugin_manager { action: "install_bundle", target: "<путь к папке max-bridge>" }
```

4. Напишите боту в MAX — сообщение появится в сессии.

Обновление кода после правок:

```js
plugin_manager { action: "set_plugin", target: "include:max-bridge", enabled: false }
plugin_manager { action: "set_plugin", target: "include:max-bridge", enabled: true }
```

## Команды

| Действие | Что делает |
|---|---|
| кнопка `🐋 Сессии` | меню сессий с названиями, закреплённые сверху |
| `/sessions`, `/сессии` | то же текстом |
| `/session`, `/сессия` | показать текущую сессию |
| `1`, `2`, … | переключиться на сессию по номеру |

Выбор сессии сохраняется в `~/.dsh/max-session.json`.

## Возможности

* доставка сообщений из MAX в сессию и ответов обратно;
* индикатор «печатает» — обновляется каждые 1.5 с, пока сессия занята;
* меню сессий на inline-кнопках: только пользовательские, архивные и старше трёх дней скрыты;
* фильтр по `chat_id` — сообщения из чужих чатов отбрасываются;
* защита от дублей при горячей перезагрузке: новый экземпляр гасит предыдущий.


## Безопасность

Токен бота хранится только локально (`~/.dsh/max-bot.json`) и не попадает в репозиторий. Плагин не исполняет произвольный текст как команды оболочки — он передаёт сообщение агенту.
