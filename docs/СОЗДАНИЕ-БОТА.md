# Создание бота в MAX и установка моста

Пошаговая инструкция: от нуля до работающего бота, через который можно
управлять агентом DeepSeek Harness из мессенджера.

Время: 10–15 минут. Понадобится: аккаунт в MAX и установленный DeepSeek Harness.

---

## Шаг 1. Платформа для ботов

Откройте **https://business.max.ru/self** и войдите под своим аккаунтом MAX.

<!-- screenshot: business.max.ru/self — главная страница платформы -->
![Главная страница платформы](img/01-platform.png)

Альтернативный вход — мини-приложение «MAX для бизнеса»:
**https://max.ru/business_bot**

---

## Шаг 2. Создание бота

В левом меню выберите раздел **«Чат-боты»** и нажмите **«Создать бота»**.

<!-- screenshot: раздел Чат-боты, кнопка Создать бота -->
![Раздел «Чат-боты»](img/02-bots.png)

Заполните:

| Поле | Что писать |
|---|---|
| Название | любое, видно пользователям (например, «Мой ассистент») |
| Описание | коротко, для чего бот |
| Аватар | необязательно |

Нажмите **«Создать»**.

<!-- screenshot: форма создания бота -->
![Форма создания](img/03-create.png)

---

## Шаг 3. Токен

Откройте созданного бота, нажмите **⋮ → Настройки** и скопируйте значение
из поля **«Токен»** (значок копирования справа от поля).

<!-- screenshot: настройки бота, поле с токеном -->
![Токен бота](img/04-token.png)

Токен выглядит как длинная строка из букв, цифр и символов `_` и `-`.
**Никому его не передавайте**: он даёт полный доступ к боту.

---

## Шаг 4. Первое сообщение боту

Найдите своего бота в MAX (по названию) и отправьте ему любое сообщение —
например, `привет`.

Это важно: бот не может писать первым, а мост должен узнать `chat_id`
диалога. Установщик заберёт его автоматически после того, как вы напишете.

---

## Шаг 5. Установка моста

Запустите **`MaxBridge-Setup.exe`** (или `install.cmd` из релиза).

<!-- screenshot: окно установщика -->
![Установщик](img/05-installer.png)

1. Вставьте токен в поле.
2. Нажмите **«Проверить»** — установщик покажет имя бота, если токен верный.
3. Нажмите **«Установить»**.
4. Если попросит — отправьте боту ещё одно сообщение, чтобы установщик
   поймал `chat_id`.
5. Готово: приложение перезапустится, плагин начнёт работать.

---

## Шаг 6. Проверка

Напишите боту `привет`. Должно прийти:

1. индикатор «печатает» — пока агент работает;
2. ответ — тот же, что вы видите в приложении.

Под каждым сообщением будет панель:

```
🐋 Сессии   ➕ Новая   ❌ Del
```

---

## Что умеет бот

| Кнопка / команда | Действие |
|---|---|
| `🐋 Сессии` | список сессий с названиями |
| нажатие на название | карточка: `✅ Вход`, `✏️ Rename`, `❌ Удалить` |
| `➕ Новая` | создать сессию и переключиться на неё |
| `❌ Del` | удалить текущую сессию (в архив, с подтверждением) |
| `/sessions` | меню текстом |
| `/session` | показать текущую сессию |

---

## Если что-то не работает

| Симптом | Причина | Что делать |
|---|---|---|
| Бот молчит совсем | неверный токен | проверить кнопкой «Проверить» |
| «печатает» есть, ответов нет | не выбран `chat_id` | написать боту ещё раз |
| Бот не появился в списке | не завершён шаг 4 | найти бота по названию и написать |
| Ответы приходят не в ту сессию | выбрана другая сессия | `🐋 Сессии` → нужная → `✅ Вход` |

---

## Безопасность

* Токен хранится локально в `~/.dsh/max-bot.json` и никуда не отправляется.
* Плагин принимает сообщения **только** из вашего чата (`chat_id`); чужие
  сообщения отбрасываются.
* Репозиторий: https://github.com/skyw0ker-su/max-bridge
